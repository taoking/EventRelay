# EventRelay 产品需求

## 产品定位

EventRelay 是“事件通知与 Webhook 可靠投递平台”。

目标是让业务系统只负责产生事件，由 EventRelay 负责事件持久化、订阅匹配、异步投递、失败记录、重试、死信、重放、签名与幂等等可靠性能力。

## 核心对象（未来阶段）

- Endpoint：Webhook 目标地址及配置。
- Event：业务系统产生的事件。
- Subscription：Endpoint 订阅哪些事件类型。
- Delivery：某 Event 向某 Endpoint 的一次逻辑投递。
- DeliveryAttempt：Delivery 的一次实际 HTTP 尝试。

## v0.1 规划

1. Endpoint CRUD
2. Event 接收 API
3. Event 持久化
4. Subscription
5. Delivery 模型
6. 异步 Delivery Job
7. HTTP Webhook 投递
8. DeliveryAttempt
9. 基础 Retry
10. Replay API

## Phase 0 范围

Phase 0 不实现任何上述业务功能，只建立工程 Harness。
