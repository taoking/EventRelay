# 测试原则

## 测试层次

- Unit Test：纯业务规则、值对象、策略。
- Feature/Integration Test：HTTP、数据库、队列边界等真实协作。
- Runtime Validation：应用启动、真实依赖、关键路径运行。

## 规则

1. Bug 修复应尽量新增 Regression Test。
2. 新增行为必须覆盖成功路径与关键失败路径。
3. 不为了测试方便而改变生产行为。
4. Mock 用于明确的外部边界，不应把核心业务全部 Mock 掉。
5. 删除已有测试必须说明该测试为何失效以及替代测试是什么。
6. `Tests PASS` 不等于 `Runtime PASS`。

## 状态

测试/验证只允许：PASS / FAIL / BLOCKED / NOT RUN。
