# 质量评级

用于 Weekly GC / Monthly Architecture Review 观察趋势，不作为单一 Merge Gate。

等级：A / B / C / D。

评估维度：

- 架构一致性
- 测试完整度
- 重复实现
- 模块复杂度
- 文档一致性
- 错误处理
- 依赖健康度
